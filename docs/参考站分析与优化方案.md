# 三个新参考站的设计分析与优化方案

> 参考来源：`xhblog.top/blog/friends/`、`nyac.at/`、`blog.cloudwings.xyz/`
> 分析日期：2026-10-24
> 分析方法：Playwright 抓取 computed style + 截图 + 主题 CSS 源码（见 `scripts/capture-refs3.mjs`、`scripts/capture-refs3-deep.mjs`）

---

## 一、三个站各自强在哪

### 1. xhblog.top —— 插画全屏 + 悬浮玻璃卡片

**实测参数**

| 项 | 值 |
| --- | --- |
| body 底色 | `rgb(248, 250, 252)` |
| body 字号 | 16px |
| 圆角 | 35 处 > 10px（20px 级别） |
| 阴影 | 8–15 处 |
| 渐变 | 8–10 处 |
| 固定元素 | `astro-loading-indicator`、顶部阴影条、右侧滚动按钮组 |
| 特色 | 页面切换过渡（`hasTransition: true`） |

**值得抄的**

1. **横幅封面 + 标题压图**。首页是一整幅插画铺满，标题「雪花の博客」直接压在插画上，下方一个半透明圆角卡片承载头像、简介和社交按钮。视觉记忆点极强。
2. **文章列表图文分栏**。列表项左侧是封面图，右侧是「标题 + 日期/字数/阅读时间 + 摘要 + 标签」，底部一个 `more →` 按钮。
3. **侧边作者名片**。常驻左栏的头像、昵称、简介、社交图标堆叠 —— 比纯导航有用。
4. **页面切换过渡**。Astro + Swup 实现路由切换时的淡入淡出 + 顶部进度条。
5. **友链头像卡片墙**。每张卡是一张彩色渐变头图 + 圆形头像 + 名字 + 一句话描述。
6. **右侧悬浮按钮组**（回到顶部 / 上下篇 / 关闭）。

### 2. nyac.at —— 极简单列，像素级克制

**实测参数**

| 项 | 值 |
| --- | --- |
| body 底色 | `rgb(237, 248, 246)`（薄荷绿，不是纯白） |
| body 字号 | 16px |
| canvas / Live2D | **0 个**（角色是静态 PNG，不是 Live2D） |
| 交互元素 | 仅 14 个链接，零 JS 框架 |
| 布局 | 左侧细分割线菜单列表 + 右侧角色立绘 |

**值得抄的**

1. **列表项右侧带缩略图**。标题 + 日期 + 摘要（2 行）+ 缩略图，缩略图右对齐悬挂在文字旁边。
2. **淡淡的底色**。`#edf8f6` 这种带色相的浅底比纯白更耐看，长时间阅读不刺眼。
3. **角色立绘不干扰正文**。固定在右下角，**不随滚动移动**，也不带气泡。
4. **菜单用细分割线列表**。每个菜单项下面一条 1px 虚线，没有背景色块。
5. **首屏极简**：一个居中的白色卡片，里面只有一句问候 + 菜单 + 一排社交图标。什么都没说，但很舒服。

### 3. blog.cloudwings.xyz —— 双栏信息架构，信息密度高

**实测参数**

| 项 | 值 |
| --- | --- |
| body 字号 | 16px |
| 主栏宽 | 872px（`--toc-width: calc((100vw - 75rem) / 2 - 1rem)`） |
| 阴影 / 大圆角 / 渐变 | 4 / 9 / 1（**克制**） |
| 固定元素 | 顶栏 sticky、返回顶部按钮、右侧 TOC（fixed） |
| 特色 | Tailwind + Swup 双栏布局 |

**值得抄的**

1. **左栏 + 右内容**。左侧 280px 常驻信息栏（头像卡片 / 分类带数量 / 标签云），右侧 872px 内容区。**列表页和文章页用同一套骨架**，一致性很强。
2. **元信息带图标**。文章卡片顶部一行：`📅 2026-09-25　📖 BASE　# 标签`，每个元素前面一个小图标。
3. **字数 + 预计阅读时间**。`67 字 | 1 分钟`，对短文特别友好。
4. **分类带数量徽章**。`未分类 1`、`项目 2`、`BASE 1`、`CS 2`，右对齐灰底圆角徽章。
5. **文章卡片右侧留白箭头**。右边一个淡蓝竖条 + `>`，hover 时高亮 —— 明确暗示"可点击"。
6. **上下篇分栏卡片**。底部左右两块，左边上一篇右边下一篇，各带方向箭头。
7. **归档页用查询参数筛选**：`/archive/?category=CS&tag=命令行`，分类和标签可以叠加筛选。

## 二、当前站点的差距

已有（SilverGo 等宽极简风）：Maple Mono 等宽中文、主色 `#21759b`、12px 基准、950px 主栏、通栏封面、圆形日期徽章、标题左竖线、文章页 TOC/上下篇/相关文章、⌘K 搜索、写作台、Live2D 看板娘、明暗双主题。

**缺口**：

| 缺口 | 参考来源 | 优先级 |
| --- | --- | --- |
| 列表项信息密度低（无缩略图/字数/阅读量） | nyac, cloudwings | 高 |
| 元信息没有图标，纯文字 | cloudwings | 中 |
| 分类没有数量徽章 | cloudwings | 中 |
| 上下篇是朴素链接，不够"可点击" | cloudwings | 中 |
| 侧栏只有标签/分类/工具，没有作者名片 | xhblog, cloudwings | 高 |
| 列表页与文章页骨架不一致 | cloudwings | 高 |
| 没有页面切换过渡 | xhblog | 中 |
| 背景纯白，长时间阅读偏刺眼 | nyac | 低 |
| 友链页是文字卡片，没有头像墙 | xhblog | 低 |

## 三、三套可选方案

### 方案 A · 轻量增强（改动最小，约半天）

不动骨架、不动色板、不动字体，只补"信息密度"和"可点击暗示"。

**A1. 列表项补三件套**（`nyac` + `cloudwings`）

```astro
<!-- PostCard.astro -->
<div class="pc-stats">
  <span><Icon name="calendar" /> {dateStr}</span>
  <span><Icon name="clock" /> {readTime} 分钟</span>
  <span><Icon name="text" /> {wordCount} 字</span>
</div>
```

缩略图右对齐（`nyac` 手法），无封面图时自动隐藏。

**A2. 元信息加图标**（`cloudwings`）—— 用内联 SVG，不引图标库。

**A3. 分类数量徽章**（`cloudwings`）

```css
.cat-badge {
  font-family: var(--font-mono);
  font-size: 1.15rem;
  color: var(--fg-mute);
  background: var(--bg-soft);
  border-radius: var(--radius-xs);
  padding: 0.1em 0.5em;
}
```

**A4. 上下篇改分栏卡片 + 右侧箭头**（`cloudwings`）

```css
.post-nav { display: grid; grid-template-columns: 1fr 1fr; gap: 1.2rem; }
.pn-item {
  padding: 1.2rem 1.4rem;
  border: 1px solid var(--border);
  border-radius: var(--radius-xs);
}
.pn-item::after {
  content: '→';
  float: right;
  color: var(--color-primary-light);
  opacity: 0.5;
}
.pn-item:hover { border-color: var(--color-primary); }
```

**A5. 背景改微色**（`nyac`）

```css
:root { --bg: #f7f9fa; --bg-soft: #fff; }   /* 正文区用白，卡片区用微色 */
html.dark { --bg: #17191c; --bg-soft: #1f2226; }
```

**成本**：约 0.5 天 · **风险**：极低 · **保留**：现有全部功能与视觉语言

### 方案 B · 双栏信息架构（推荐，约 1.5 天）

这是三个参考站优点**融合得最好**的一套，也是最贴合当前站点已有功能的一套。

**B1. 全站统一「左信息栏 + 右内容」骨架**

```
┌──────────────┬────────────────────────────┐
│  作者名片     │  ← 头像 / 昵称 / 简介 / 社交  │
│  ─────────   │                            │
│  分类 (徽章)  │      内容区 872px          │
│  ─────────   │                            │
│  标签云      │                            │
│  ─────────   │                            │
│  归档树      │                            │
│  ─────────   │                            │
│  快捷入口     │                            │
└──────────────┴────────────────────────────┘
```

- 侧栏 sticky 常驻（`cloudwings`）
- 移动端折叠成顶部横向滚动条

**B2. 文章页 TOC 移入左栏 + 阅读进度**

当前 TOC 在右侧 260px。改成左栏后：
- 正文区可以更宽（872px → 更好读）
- TOC 跟随滚动高亮当前章节
- 顶部加一条 2px 阅读进度条（`xhblog` 的顶部阴影条）

**B3. 视差滚动封面**（`xhblog`）

```css
.post-banner { height: 42vh; overflow: hidden; }
.pb-bg {
  background-image: url('/img/bg/hero.svg');
  background-attachment: fixed;      /* 视差 */
  background-size: cover;
}
@media (prefers-reduced-motion: reduce) {
  .pb-bg { background-attachment: scroll; }
}
```

**B4. 页面切换过渡**（`xhblog` Swup）

用 Astro 内置的 `<ClientRouter />`（Astro 5+ 的 View Transitions）：
- 路由切换淡入淡出
- 顶部 2px 进度条
- 尊重 `prefers-reduced-motion`

**B5. 友链页改头像卡片墙**（`xhblog`）

```astro
<a class="fc-card">
  <div class="fc-cover" style="--c1:#...; --c2:#..."></div>
  <img class="fc-avatar" src="..." />
  <div class="fc-name">冷汐OωO</div>
  <div class="fc-desc">有趣的宝藏博客</div>
</a>
```

**B6. 归档页支持分类+标签叠加筛选**（`cloudwings`）

`/archive/?category=OI&tag=分块` —— 纯客户端筛选，不需要重新构建。

**成本**：约 1.5 天 · **风险**：中（要动布局组件） · **保留**：全部现有功能

---

### 方案 C · 沉浸式插画（约 2 天）

**C1. 首页全屏插画 + 标题压图**（`xhblog`）

```css
.hero-banner {
  height: 100vh;
  background-image: url('/img/bg/hero-full.webp');
  background-size: cover;
}
.hero-title {
  color: #fff;
  text-shadow: 0 4px 20px rgb(0 0 0 / 0.5);
}
```

**C2. 文章卡片封面图左右分栏**（`xhblog` 核心手法）

```css
.post-card { display: grid; grid-template-columns: 1fr 220px; gap: 1.4rem; }
.post-card .cover { order: 2; border-radius: var(--radius-md); }
```

**C3. 玻璃拟态卡片 + 粉紫主色**（`xhblog` 色板）

**C4. 看板娘角色图** —— 用生成的高质量角色立绘替换当前线稿静态图。

**成本**：约 2 天 + 插画素材
**风险：高** —— 玻璃拟态 + 粉紫 + 20px 圆角与用户上次明确否决的"玻璃拟态 SaaS 风"重合，
虽然参考站本身做得很好，但**偏离了用户上次要求的 SilverGo 等宽极简风**。
如果选 C，建议做成**可切换主题**（保留简版 / 插画版两套），而不是直接替换。

## 四、我的建议

**选方案 B**，理由：

1. **与上一轮反馈不冲突**。上一轮用户明确否决了玻璃拟态/渐变/大圆角，方案 B 完全保留等宽字体 + 青蓝 + 极细线的语言。
2. **吸收的三个站优点都成立**：
   - `cloudwings` 的双栏骨架 → 解决"列表页与文章页不一致"和"侧栏信息架构弱"
   - `nyac` 的信息密度 → 解决"列表页太空"
   - `xhblog` 的过渡动画与视差封面 → 解决"静态感"
3. **投入产出比最高**。约 1.5 天能拿到三个站 80% 的可借鉴点。
4. **不破坏已有资产**。TOC、相关文章、看板娘、写作台、⌘K 搜索全部保留。

如果只想快速见效，**先做方案 A 的 A1–A4**（半天，信息密度立刻上来），之后再决定要不要上 B。

## 五、实施顺序建议（B 方案）

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| 1 | 抽 `Sidebar.astro` 组件（作者名片 / 分类 / 标签 / 归档 / 快捷入口） | 侧栏可复用 |
| 2 | BaseLayout 加 `layout` 变体：`two-col` / `full` | 页面可自由切换 |
| 3 | 列表页 + 文章页接双栏 | 骨架统一 |
| 4 | TOC 移入左栏 + 阅读进度条 | 阅读体验 |
| 5 | `<ClientRouter />` 页面过渡 | 动效 |
| 6 | 视差封面 | 视觉 |
| 7 | 归档页查询参数筛选 | 功能 |
| 8 | 友链头像墙 | 锦上添花 |

每步都可独立构建验证，不需要一次性全做完。
