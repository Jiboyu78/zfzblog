# 你好，我是 Neoma

一个正在自学计算机的蒟蒻，喜欢把踩过的坑都写下来。

这个站点既放算法题解，也放多模态实验的记录，还有一些工程上踩过的雷。

## 这个站点

- 技术栈：Astro 7 + Tailwind CSS v4 + MDX，搜索用 Pagefind，看板娘是 Live2D。
- 所有动效都是手写的 CSS 与原生 JS，没有引入重量级动画库。
- 文章全部用 Markdown 写，放在仓库里，用 Git 管理版本。

想订阅？[RSS](/rss.xml) 是最省事的；想看看源码？去 [GitHub 仓库](https://github.com/Jiboyu78)。
