📝 内容管理后台

Decap CMS 需要先配置 GitHub OAuth 才能使用。如果你不想折腾认证， 下面两个入口同样能写文章。

✍️ 打开写作台 ← 返回站点
启用 Decap CMS 的步骤：
  1. 在 GitHub Settings → Developer settings → OAuth Apps 新建应用
  2. Callback URL 填 https://api.netlify.com/auth/done
  3. 把 Client ID / Secret 填进 public/admin/config.yml
  4. 把 backend.repo 改成你的 用户名/仓库名

更省事的方式：本地直接写 src/content/blog/*.md，或者用站内写作台导出后放进去。
